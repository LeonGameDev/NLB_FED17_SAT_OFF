# Student Version - 90 Minute Team Class

This folder is intentionally incomplete. There are **36 core fill-in-the-blank tasks** and **6 optional code bonus tasks**.

Important: do not try to memorize the answers. Open `STUDENT_TASKS.md`, read the example beside each task, then fill the matching blank in the code.

The difficult parts are already finished: 78-card matching, validation, zodiac logic, database relationships, and reading history.

## Run order
1. Start Apache and MySQL in XAMPP.
2. Import `database.sql` in phpMyAdmin. It contains 78 cards and 78 possible personality questions.
3. Install packages: `pip install -r requirements.txt`
4. Complete the tasks in `STUDENT_TASKS.md`.
5. Run: `python app.py`
6. Open `http://127.0.0.1:5000`

If Flask cannot start, check the Python tasks first. If the page opens but looks wrong, check HTML/CSS tasks. If quiz buttons do not work, check JavaScript tasks.
